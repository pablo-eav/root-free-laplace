Primeros Pasos (Getting Started)

Paso 1: Instalación Permanente en MATLAB

Abra MATLAB, navegue hasta la carpeta de la toolbox y ejecute:

>> install_toolbox

Esto añade permanentemente todos los directorios al path de MATLAB y ejecuta un test de autodiagnóstico.

Paso 2: Validación del Sistema

Verifique que todos los algoritmos numéricos operan con precisión de máquina ejecutando la suite de pruebas:

>> run_all_tests

Las 5 baterías de pruebas unitarias (Fujiwara, Stirling, Laguerre, Órdenes Masivos e Inversión Híbrida) deben pasar al 100%.

Paso 3: Su Primera Inversión Numérica

% Definir numerador y denominador
num = [1];
den = [1, 2, 2]; % s^2 + 2*s + 2

% Definir vector temporal
z = linspace(0, 10, 300);

% Invertir
[f, info] = laplace.invert(num, den, z);

% Ver diagnóstico
disp(info);

Paso 4: Sistemas Masivos con FactorPoly ($K = 100$)

% F(s) = 1 / (s + 1)^100
den_factor = laplace.FactorPoly('roots', -ones(100, 1));
z = linspace(0, 150, 400);

[f, info] = laplace.invert(1, den_factor, z);
plot(z, f);
title('Respuesta de Cascada de Orden 100');
