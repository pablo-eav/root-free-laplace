Casos de Estudio y Ejemplos de Ingeniería

Ejemplo 1: Sistema Racional Subamortiguado de 2º Orden

Script: examples/ex01_basic_rational.m

Función de Transferencia: $F(s) = \frac{1}{s^2 + 2s + 2}$

Solución Analítica: $f(z) = e^{-z} \sin(z)$

Demuestra la inversión sin cálculo de raíces con error $L_\infty < 10^{-6}$ en menos de 1 milisegundo.

>> ex01_basic_rational

Ejemplo 2: Banco de 5,000 Resonadores Armónicos (Grado $K = 10,000$)

Script: examples/ex02_harmonic_5000.m

Función de Transferencia: $Q(s) = \prod_{k=1}^{5000} (s^2 + k^2), \quad F(s) = \sum_{k=1}^{5000} \frac{k}{s^2 + k^2}$

Solución Analítica: Núcleo de Dirichlet trigonométrico $f(z) = \frac{\sin(5000 z / 2)\sin(5001 z / 2)}{\sin(z/2)}$

Validación de 10,000 polos puramente oscilatorios no amortiguados sin desbordar memoria con concordancia $L_\infty < 10^{-11}$.

>> ex02_harmonic_5000

Ejemplo 3: Red Distribuida Chebyshev de 1,000,000 de Polos

Script: examples/ex03_chebyshev_1000000.m

Función de Transferencia: $F(s) = \frac{1}{U_N(1 + s/\text{denom}) - U_{N-1}(1 + s/\text{denom})}, \quad N = 1,000,000$

Demuestra que la arquitectura en bloques de PartialFractions evalúa 1 millón de modos distribuidos en menos de 10 milisegundos.

>> ex03_chebyshev_1000000

Ejemplo 4: Difusión Térmica Unidimensional (Escalón)

Script: examples/ex04_diffusion_step.m

Función de Transferencia: $F(s) = \frac{1}{s \cosh(\sqrt{s})}$

Solución Analítica: Expansión de función de error complementario (tiempos cortos) y serie de Fourier modal (tiempos largos).

Aproximada mediante producto de 80 modos en FactorPoly con error $L_\infty < 10^{-4}$.

>> ex04_diffusion_step
