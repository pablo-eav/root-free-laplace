1. El Problema de la Inversión Numérica de Laplace sin Raíces

El cálculo de raíces polinomiales en grados $K > 30$ está matemáticamente mal condicionado debido al fenómeno de Wilkinson: perturbaciones del orden de la precisión de máquina ($10^{-16}$) en los coeficientes desplazan las raíces en órdenes de magnitud. Asimismo, la evaluación clásica de Taylor alrededor de $z=0$ produce la joroba de Taylor con cancelaciones numéricas catastróficas.

Esta toolbox resuelve ambos problemas mediante una arquitectura híbrida de tres pilares:

2. Cota Espectral de Fujiwara $O(K)$ y Horizonte Causal Seguro

Para un denominador mónico $B(s) = s^K + b_1 s^{K-1} + \dots + b_K$, el radio espectral de los polos está estrictamente acotado por:

Rfuj = 2 · max { |b1/2|, |b2|1/2, |b3|1/3, ..., |bK-1|1/(K-1), |bK/2|1/K }

El horizonte causal seguro en precisión IEEE 754 doble (53 bits) antes de la joroba de Taylor se establece analíticamente en:

zfuj = 35 / Rfuj

3. Mapeo Conformal de Möbius y Base Ortogonal de Laguerre

Para $z > z_{\text{fuj}}$, el semiplano derecho $\text{Re}(s) > 0$ se proyecta biyectivamente sobre el disco unitario abierto $\mathbb{D} = \{w \in \mathbb{C} : |w| < 1\}$:

s = a · (1 + w) / (1 - w)  ⇔  w = (s - a) / (s + a),   a > 0

La transformada de Laplace se expande como:

G(w) = [ 2a / (1 - w) ] · F(a(1+w)/(1-w)) = ∑n=0∞ cn wn

La inversión exacta en el dominio temporal se recupera en la base ortogonal amortiguada de Laguerre:

f(z) = exp(-a·z) · ∑n=0∞ cn Ln(2·a·z)

Donde $L_n(x)$ se evalúa mediante la relación de recurrencia estable de 3 términos de Favard sin división por cero:

(n + 1) Ln+1(x) = (2n + 1 - x) Ln(x) - n Ln-1(x)

4. Serie de Laurent en Espacio Logarítmico de Stirling

Para fracciones con grado relativo $\delta = \text{deg}(B) - \text{deg}(A) \ge 1$:

f(z) = zδ - 1 · ∑n=0N-1 αn zn,   αn = cn / Γ(δ + n)

Para evitar desbordamiento por factoriales enormes, los coeficientes $\alpha_n$ se computan rigurosamente en espacio logarítmico con la expansión de 5 términos de Stirling:

ln Γ(x) ∼ 0.5 ln(2π) + (x - 0.5) ln(x) - x + 1/(12x) - 1/(360x3) + 1/(1260x5) - 1/(1680x7)

5. Identidades de Newton-Girard para Formas Factorizadas (FactorPoly)

Para denominadores de grado $K = 1,000,000$ dados en factores lineales $(s - r_k)$ y cuadráticos $(s^2 + b_j s + c_j)$, las sumas de potencias $S_m = \sum s_k^m$ se extraen sin expandir polinomios vía:

w0 = 2,   w1 = -bj,   wm = -bj wm-1 - cj wm-2
k · ck = ∑j=1k ck-j (Sj(B) - Sj(A))
